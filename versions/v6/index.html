資料處理說明

漲跌幅排行取 STOCK_DAY_ALL（每日收盤行情），以個股收盤價與漲跌價差換算漲跌幅百分比後排序。母體為上市普通股，排除 ETF／ETN／受益證券與 TDR，並排除無成交、無收盤價、無漲跌價差者，共 1,075 檔；排序為漲幅由高至低、跌幅由低至高，同名次以股票代號升冪為次要鍵。

成交量為「成交股數 ÷ 1,000」換算為張；成交金額為「成交金額 ÷ 108」換算為億元。

走勢圖取 近 60 個交易日（2026/07/02–2026/09/24）之收盤指數與成交金額，來源為 FMTQIK；收盤指數並與 MI_5MINS_HIST 逐日交叉驗證。

MA5／MA20 為簡單移動平均，以完整歷史（281 個交易日，2025/08/01–2026/09/24）計算後取最近 60 日呈現，因此區間內每一點都有值，無起點斷線。均線單位為指數點。

MA 交叉事件同樣由上述 281 日歷史計算：以每日收盤值求 MA5 與 MA20，逐日比較其差值，差值由負轉正（MA5 上穿 MA20）記為黃金交叉、由正轉負（MA5 下穿 MA20）記為死亡交叉，共 14 筆，全數由實際收盤資料算出，未經人工指定；其中 4 筆落在走勢圖的 60 日區間內並於圖上以垂直虛線、圓點與日期標籤標示。

成交量副圖採成交金額（億元）作為量能指標，柱色依當日收盤相對前一交易日漲跌著色（紅漲、綠跌，台股慣例）；本區間 31 天上漲、29 天下跌。

即時更新：點「重新整理」後，前端以 fetch 直接呼叫上列 www.twse.com.tw 端點。實測 mis.twse.com.tw（getStockInfo.jsp）未回傳 Access-Control-Allow-Origin，瀏覽器跨來源 fetch 會被 CORS 阻擋，且該端點不支援 JSONP callback（回傳內容不會包成 callback(...)），故不採用；本頁改用同樣由證交所提供、且具 CORS 標頭的 www.twse.com.tw 端點。盤中為延遲約 5 秒至 1 分鐘之資料，非逐筆即時報價。

大盤即時採 MI_5MINS_INDEX 期間最後一筆之發行量加權股價指數；個股即時採 STOCK_DAY_ALL 之收盤價、漲跌價差、成交股數與成交金額（換算為張與億元），並重新計算漲跌幅排行；漲跌家數與成交金額採 MI_INDEX type=MS。

排行排除規則：非 4 碼代號（ETF／ETN／受益證券）、0xxx ETF、名稱結尾 -DR 之 TDR、成交股數為 0 或空白、收盤價空白（官方列為「未成交」或「無比價」），以及漲跌價差無法解析者，一律不納入排行。

MA5／MA20 均線與成交量副圖仍為內建快照，不隨「重新整理」變動（歷史日資料端點於盤後更新，非盤中即時）；但會由 GitHub Actions 每日排程自動更新，因此重新載入頁面即可看到最新收盤的均線與成交量。
