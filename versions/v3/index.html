資料處理說明

個股收盤價與漲跌經 STOCK_DAY_ALL 與 MI_INDEX type=ALL 兩個官方來源交叉驗證，10 檔全數一致。

成交量為「成交股數 ÷ 1,000」換算為張；成交金額為「成交金額 ÷ 108」換算為億元。

走勢圖取 近 60 個交易日（2026/07/02–2026/09/24）之收盤指數與成交金額，來源為 FMTQIK；收盤指數並與 MI_5MINS_HIST 逐日交叉驗證，60 日全數一致。

MA5／MA20 為簡單移動平均，以完整歷史（144 個交易日）計算後取最近 60 日呈現，因此區間內每一點都有值，無起點斷線。均線單位為指數點。

成交量副圖採成交金額（億元）作為量能指標，柱色依當日收盤相對前一交易日漲跌著色（紅漲、綠跌）。

即時更新：點「重新整理」後，前端以 fetch 直接呼叫上列 www.twse.com.tw 端點。實測 mis.twse.com.tw（getStockInfo.jsp）未回傳 Access-Control-Allow-Origin，瀏覽器跨來源 fetch 會被 CORS 阻擋，且該端點不支援 JSONP callback（回傳內容不會包成 callback(...)），故不採用；本頁改用同樣由證交所提供、且具 CORS 標頭的 www.twse.com.tw 端點。盤中為延遲約 5 秒至 1 分鐘之資料，非逐筆即時報價。

大盤即時採 MI_5MINS_INDEX 期間最後一筆之發行量加權股價指數；個股即時採 STOCK_DAY 當月最後一筆之收盤價、漲跌價差、成交股數與成交金額（換算為張與億元）。漲跌家數與成交金額採 MI_INDEX type=MS。

MA5／MA20 均線與成交量副圖仍為內建快照，不隨「重新整理」變動（歷史日資料端點於盤後更新，非盤中即時）。

若 API 無法連線（離線、證交所端點異常或 CORS 變更），頁面會自動退回內建快照並以紅色提示標示，不會顯示空白或錯誤數字。
